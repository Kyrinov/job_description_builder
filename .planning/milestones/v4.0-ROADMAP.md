# Milestone v4.0: Seven-Elements Conversational Architecture

**Status:** ✅ SHIPPED 2026-06-26
**Phases:** 26–29
**Total Plans:** 9

## Overview

v4.0 surfaces all 7 Part 2 sections of the TBS Accessible JD Template as a natural
conversational experience. Two new WorkDescription fields (`org_context`,
`responsibilities_narrative`) are added, connected to a seven-element completeness
audit, exposed as structured JSON/CSV export for workforce analytics, and branched
into a Manager-Track UX that hides classification internals from hiring managers.
The "Facebook Pattern": Julian's structured data is captured invisibly through
conversation and exported machine-readable.

## Milestone Summary

**Key Decisions:**

- **Co-update rule** — every new typed WD field (`org_context`, `responsibilities_narrative`, `wd_type`) added to `WorkDescription` and `WDPatchRequest` in the same commit, preventing silent field drop on PATCH round-trip.
- **stepIndex resume-by-last-answered** — replaced the brittle `useState(0)` step index with a lazy initializer that derives position from the last answered step, landed BEFORE any STEPS insertion so existing localStorage sessions survive STEPS growth.
- **`build_seven_elements(wd)` as single source of truth** — one helper feeds the completeness audit, JSON export, and CSV export, so element status logic never diverges.
- **Typed-field-only completeness audit** — Organizational Context status reads `wd.org_context` (the typed root field), not the derived fallback text, so a record with branch/reports data but no typed org_context correctly reads "missing".
- **userRole out of the data model** — manager/advisor role lives in localStorage only and is explicitly rejected on PATCH; the track is expressed in the WD via the separate `wd_type` field.

**Issues Resolved:**

- CR-01 (Phase 26): SPA `commit()` mirror list omitted `org_context`, causing silent data-loss on SPA→export — fixed in 02fb8d6.
- Post-milestone hardening (quick task 260626-ejt + follow-up fixes): org-context synthesis bounded with a 30s client timeout, toast no longer hangs, step auto-advances on synthesis completion, redundant org-context fields pruned (placement/reporting already captured in Phase 0).

**Issues Deferred (Technical Debt):**

- Manager-track **poster and PDF** exports lack the DRAFT watermark applied to the manager DOCX (Phase 28 MAJ-01 / Phase 29 MAJ-01).
- CSV **formula injection** not neutralized — accepted per T-29-02-03 disposition (internal HR tool, trusted input).
- Deferred to v5 (per REQUIREMENTS): SJD pre-fill for org_context, DND org-unit dropdown, NOC→OaSIS crosswalk in JSON export, dedicated Effort/Working Conditions Socratic steps.
