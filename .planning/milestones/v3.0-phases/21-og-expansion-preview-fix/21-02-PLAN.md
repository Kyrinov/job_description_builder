```css

  flex: 1 1 auto; min-height: 0; overflow-y: auto;
  padding: 38px 34px 80px;
  display: flex; justify-content: center;
}
```

Change the last declaration line by appending `align-items: flex-start` to it:
```css
.doc-scroll {
  flex: 1 1 auto; min-height: 0; overflow-y: auto;
  padding: 38px 34px 80px;
  display: flex; justify-content: center; align-items: flex-start;
}
```

ONLY change this one rule. Do not modify any adjacent rules, `.doc`, `.doc-page`, or any other selector. The entire change is the addition of a single CSS declaration.

Root cause: `align-items` defaults to `stretch` in a flex container, which causes `.doc` (the white paper element) to stretch to fill the full height of `.doc-scroll`. With `flex-start`, `.doc` takes its natural content height and the scroll container handles overflow naturally.
