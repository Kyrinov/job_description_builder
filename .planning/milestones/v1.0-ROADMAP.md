## Overview

JD Builder v1.0 MVP — a DND-first Government of Canada job description builder for HR advisors and classification specialists. An advisor describes the work to be performed in plain language; the system maps that description to authoritative NOC profiles, suggests an occupational group and level, and generates a fully traced job description grounded in NOC, collective agreements, job evaluation standards, and TBS policy.

Delivered a complete end-to-end HTMX wizard: NL→NOC mapping → OG classification → JD generation → JES scoring → DOCX export with provenance citations and DRF linkages.

## Milestone Summary

**Key Decisions:**

- FastAPI over Flask — LLM streaming via StreamingResponse; Flask WSGI blocks during Ollama calls
- HTMX 2.x + Alpine.js 3.x — No build step; ~29KB combined; server-rendered wizard pattern
- SQLite + sqlite-vec (not DuckDB) for app state — app state and vector search co-located
- DashScope qwen3-max for Stage 3 LLM — local gemma4:31b too slow (6 min/request); cloud inference via dashscope-intl.aliyuncs.com
- instructor over raw Ollama format — mandatory retry wrapper for local model structured output edge cases
- docxtpl table-row loops use for/data/endfor in separate rows — patch_xml regex is greedy
- Phase 8 template committed as binary artifact + reproducible build script — loads deterministically at runtime
- Phase 9 WorkDescription extended with is_dnd_position + drf_linkages (additive-optional, schema_version stays at 1)
- Phase 9 inline-panel pattern (revised): DRF UI on /wizard/export, not a separate /wizard/drf step; is_dnd_position defaults to True

**Issues Resolved:**

- NOC 2021 unit group profiles not available in prototype — collected and indexed
- TBS OCHRO OG definitions not collected — scraped from Canada.ca (2026-06-02); 33 OG definitions, 81 unique og_codes
- Export blocked when JES scoring produced malformed output — Phase 8.1 inserted with per-factor retry + advisor override

**Issues Deferred:**

- noc_fts DDL bug in app/db.py (UNINDEXED + content='' — deferred from Phase 4)
- Starlette TemplateResponse deprecation warning (deferred from Phase 4)
- WeasyPrint PDF export (PDF endpoint returns 501 — deferred; DOCX is the primary export)
- TBS Qualification Standards per OG — required for v2 QUAL-01
- Full CA active validation (CA-02, CA-03) — infrastructure in place (CA-01), enforcement deferred to v2

**Technical Debt Incurred:**

- 02-02-SUMMARY.md was never written (Phase 2, Plan 02-02)
- REQUIREMENTS.md traceability table not updated during phase execution — corrected at milestone close
