## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-04-01 | Tampering | og_results.html — {{ candidate.definition_excerpt }} rendering | mitigate | Jinja2 auto-escaping is enabled by default in FastAPI TemplateResponse; TBS source text contains no HTML; verbatim text from og_definitions is safe for rendering — accept residual risk of TBS file containing HTML tags (low probability for official policy documents) |
| T-05-04-02 | Tampering | HTML form og_code hidden input | accept | og_code is echoed back as a hidden input in og_results.html; the confirm endpoint validates og_code against OG_LEVELS (Plan 05-03 T-05-03-01); a modified og_code not in OG_LEVELS returns 422 |
| T-05-04-03 | Denial of Service | Large og_definitions text in LLM context | accept | definition_excerpt capped at 400 chars, inclusions at 400, exclusions at 300 in og_classifier.py; full text is never rendered to browser; single-user local tool, no flood risk |
