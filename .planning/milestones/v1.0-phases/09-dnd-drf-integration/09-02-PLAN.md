Create app/services/drf_service.py with the following public API:

```python
async def get_drf_candidates(wd_id: str, db_path: str) -> dict:
    """Return DRF program linkage candidates for a WorkDescription's duties.

    Keyword matching algorithm:
    1. Load all rows from drf_rows table.
    2. Collect all confirmed duty text (draft_duties + advisor_additions).
    3. Tokenize combined duty text: lowercase, split on whitespace + punctuation,
       remove stopwords (set: {'the','a','an','and','or','of','to','in','for',
       'with','that','this','is','are','be','by','on','at','as','it','its',
       'from','have','has','was','were','will','can','may','not','but','if',
       'their','they','we','our','you','your'}).
    4. For each drf_row, count tokens in search_text that appear in the duty token set.
    5. Keep rows with score >= 1. Sort descending by score.
    6. Return dict: {wd_id, is_dnd_position, candidates: [list of candidate dicts]}

    Each candidate dict:
        id: int (drf_rows.id)
        core_responsibility: str
        departmental_result: str
        fiscal_year: str
        score: int (overlap token count)

    Returns candidates=[] when is_dnd_position=False (no error raised).
    """

async def confirm_drf_linkages(wd_id: str, row_ids: list[int], db_path: str) -> dict:
    """Store advisor-confirmed DRF linkages on the WorkDescription.

    For each row_id in row_ids, fetches the drf_rows record and appends a dict to
    wd.drf_linkages:
        {
            core_responsibility: str,
            departmental_result: str,
            fiscal_year: str,
            row_index: int,          # = drf_rows.id
            confirmed: True,
            provenance_source_id: str  # = "DRF/" + str(drf_rows.id)
        }

    Replaces any existing drf_linkages (idempotent re-confirm).
    Saves WD with save_work_description. Stage is NOT advanced (stays in current stage).

    Returns dict: {wd_id, confirmed_count: int, drf_linkages: list[dict]}
    """
```

Implementation notes:
- Use `asyncio.to_thread` for all DB calls (same pattern as jes_service.py).
- Import: `from app.db import get_connection`, `from app.services.wd_store import load_work_description, save_work_description`, `from app.models.work_description import WorkDescription, ProvenanceTag`.
- Token set construction: `import re; tokens = set(re.findall(r'[a-z]+', combined_text.lower()))` then subtract STOPWORDS.
- DRF row search_text tokenization: `set(re.findall(r'[a-z]+', row['search_text']))`.
- Overlap score: `len(duty_tokens & row_tokens)`.
- ProvenanceTag for confirmed linkages is NOT stored in drf_linkages dict — the dict stores provenance_source_id as a string. The full ProvenanceTag is constructed in the export service when building version manifest.
