accumulateSignals function (data.jsx lines 327–341):
```javascript
function accumulateSignals(answers) {
  const tally = {};
  for (const stepId of qbStepIds) {
    const ans = answers[stepId];
    if (!ans) continue;
    const sig = ans.signals;
    if (sig?.og_candidates) {
      for (const code of sig.og_candidates) {
        tally[code] = (tally[code] ?? 0) + 1;
      }
    }
  }
  return tally;
}
```
The `ans.signals` comes from the option selected — it is the signals object from the STEPS option that matches. New questions feed this automatically as long as the step ID is in qbStepIds.
