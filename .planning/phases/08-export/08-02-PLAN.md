## ASVS L1 Threat Register (STRIDE)

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-04 | Injection (SQLi) | load_work_description(conn, wd_id) | mitigate | wd_store uses parameterized queries (existing pattern); wd_id never string-formatted into SQL. |
| T-08-05 | Injection (template) | docxtpl context | mitigate | Template is a fixed committed artifact (08-01); only structured context dict values are substituted (D-05) — no user-supplied template strings rendered. |
| T-08-06 | Tampering (data integrity) | jes_total / points | mitigate | validate_export_readiness treats points is None as blocking (D-02), preventing export of a silently-wrong total. |
| T-08-07 | Repudiation | export provenance | mitigate | export_hash (SHA-256 of bytes) + exported_at recorded on the WD on every successful export (D-03), giving a verifiable export audit trail. |
| T-08-08 | Information Disclosure | rendered DOCX | accept | Single-user local app (Out of Scope: multi-tenant); WD content is the user's own data. |
| T-08-09 | Denial of Service | DocxTemplate render | accept | Render runs in asyncio.to_thread (non-blocking); single-user local workload — no rate limiting required for V1. |
