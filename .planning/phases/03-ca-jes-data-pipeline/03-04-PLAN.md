       `sqlite3 -column -header app.db "SELECT clause_type, article_ref, substr(clause_text,1,200) AS preview FROM ca_clauses WHERE og_code='EC' AND clause_type='restriction' LIMIT 5"`

    2. EC CA — scope clauses:
       `sqlite3 -column -header app.db "SELECT clause_type, article_ref, substr(clause_text,1,200) AS preview FROM ca_clauses WHERE og_code='EC' AND clause_type='scope' LIMIT 5"`
       Question: Do the previews describe who/what the agreement covers? YES / NO

    3. IT_CS multi-OG split sanity:
       `sqlite3 -column -header app.db "SELECT og_code, COUNT(*) FROM ca_clauses WHERE og_code IN ('IT','CS') GROUP BY og_code"`
       Question: Are both counts > 0 AND approximately equal? YES / NO

    4. EC JES — Decision-Making factor degree descriptors:
       `sqlite3 -column -header app.db "SELECT factor_name, degree_descriptors FROM jes_factors WHERE og_code='EC' AND factor_name LIKE '%ecision%'"`

       Question: Does the JSON list of {degree, text, points} broadly match the source TXT's degrees D1..D8 with points 5/15/35/60/90/125/165/210? Minor paraphrase is acceptable; missing degrees or wildly wrong point values are NOT acceptable. YES / NO

    5. Policy FTS5 AS vs EC retrieval (Phase 5 CLASS-03 prereq):
       `sqlite3 -column -header app.db "SELECT doc_name, substr(chunk_text,1,300) AS preview FROM policy_chunks WHERE id IN (SELECT rowid FROM policy_fts WHERE policy_fts MATCH 'AS OR EC OR classification') LIMIT 5"`
       Question: Do retrieved chunks contain text relevant to the AS-vs-EC classification distinction? YES / NO
